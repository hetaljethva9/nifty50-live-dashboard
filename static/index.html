"Move" = % distance of current price beyond the Candle-1 range. "First Breakout" = the first time today the stock's price broke past its Candle-1 high/low (tracked all day, can be any time). A confirmed flag means the original fixed rule also fired — specifically, Candle 2 (09:20–09:25) crossed Candle 1's high/low, so "confirmed" always shows 09:25 for every stock. "First Breakout" is the more informative of the two when it differs from 09:25 — it means the stock broke out later in the day, missing the strict 2-candle rule. Data via Yahoo Finance — typically ~15 min delayed, not tick-level. Auto-refreshes on the interval selected above while this tab is open.

Supertrend Flips Today table = every Supertrend direction change (period 10, multiplier 3, standard settings) that has occurred so far today on each stock's 5-min chart, most recent first. ATR is warmed up using several days of history, so flips can show up even in the first candles right after market open. A stock can appear more than once if it flipped several times during the day.
